# Отчет: Pose Estimation Project

## Цель проекта

Обнаружение пешеходов (keypoint detection) для автономного вождения с использованием knowledge distillation:

1. **Teacher model (ViTPose)** → генерирует псевдо-лейблы на пешеходах
2. **Student model** → обучается на псевдо-лейблах
3. **Цель**: сжать модель до ~100ms latency

## 2. Проекция 3D→2D bbox

### Проблема
Исходная проекция была упрощенной и давала неверные результаты - bbox не совпадали с пешеходами на изображении.

### Решение
Использована правильная цепочка преобразований:
1. **World coordinates** → читаются из nuScenes
2. **Ego coordinates** → с помощью pyquaternion
3. **Camera coordinates** → intrinsic матрица камеры
4. **Image coordinates** → проекция на 2D

Файлы:
- `src/data/extract_bboxes.py` - извлечение bbox
- `src/data/visualize_bboxes.py` - визуализация для проверки
- `check/test_correct_bbox.jpg` - визуальная верификация

### Результат
Bbox правильно накладываются на пешеходов - проверено визуально.

## 3. Фильтрация данных

### Проблема
Не все bbox полезны:
- Мало LiDAR точек → плохой bbox
- Слишком маленькие bbox → сложно детектировать keypoints
- Слишком большие bbox →可能 несколько пешеходов

### Фильтры (добавлены в коде)
```python
min_lidar_pts = 5         # минимум точек лидара
min_bbox_width = 20       # минимальная ширина
min_bbox_height = 50      # минимальная высота
max_bbox_area = 200000    # максимальная площадь
```

### Статистика фильтрации
| Этап | Количество |
|------|-----------|
| Всего пешеходов | 265,145 |
| После фильтрации | ~94,265 |
| С ключевыми точками | 41,492 |

Фильтры отсекли ~65% данных (170,880 bbox отфильтровано).

## 4. ViTPose (Teacher Model)

### Загрузка модели
- Использована `usyd-community/vitpose-base-simple` с HuggingFace
- Скачана через hf-mirror.com из-за сетевых проблем
- Загружена успешно

### Проблема с MPS
**ViTPose зависает при загрузке на Apple Silicon MPS (M1/M2/M3)**

- При загрузке модели на MPS - зависает бесконечно
- Только CPU работает стабильно

### Производительность (CPU)
- **Скорость**: ~4.0 img/s
- **Время на полный датасет**: ~2.9 часа (10,417 секунд)

### Скрипт генерации
```bash
PYTHONPATH=. .venv/bin/python src/data/generate_pseudo_labels.py \
    --device cpu \
    --min-lidar-pts 5 \
    --min-bbox-width 20 \
    --min-bbox-height 50
```
